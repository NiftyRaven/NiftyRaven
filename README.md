## Shop Inventory Tracker

Leftover bars. Remnants. Purchased parts. One PC. No cloud. MIT. Double-click start.

A leftover bar does not look like much. Eighteen inches of 2x2. A scrap of 6061 with a job number written in marker. That is how shops lose money — not in one dramatic mistake, but in a hundred quiet ones.

I built a tool for that. Then opened it so the next shop does not have to start from zero.

**[Download v1.0.0](https://github.com/NiftyRaven/shop-inventory-tracker/releases/latest)** · [source](https://github.com/NiftyRaven/shop-inventory-tracker)
